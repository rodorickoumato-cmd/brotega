## 💡 CONSEILS CULTURE AFRICAINE

### Ce qui résonne:
```
✓ "Plus vous travaillez, plus vous gagnez"
✓ "C'est transparent" (contre frais cachés)
✓ "Support local" (pas robot)
✓ "Paiement garanti" (confiance)
✓ "Famille d'affaires" (communauté)
```

### Ce qui ne marche pas:
```
✗ "Gagnez facilement" (promesse creuse)
✗ Jargon technique
✗ Frais cachés
✗ Pas de support local
✗ Processus compliqué

```
- Professionnel mais chaleureux
